What the labels mean

Planned: recorded, with implementation still ahead. In progress: recorded development or partial delivery; it does not imply an agent is currently running. Demo verification, merged source and installed production behavior are separate steps. Built — release pending: the recorded changes are built, but this list has no confirmed Optiq release for that scope. Completed: recorded as finished or resolved on the date shown; the expanded details explain the basis. Older completion records are retained, not presented as newly tested. Verification pending: existing work or reported behavior needs checking before completion or availability can be confirmed.

Needs Optiq input: a lab answer or approval is needed. Partly delivered: some parts are available, with the rest in progress. Needs verification: behavior, readiness or availability still needs checking. Meeting priorities highlights open meeting requests. Deferred requests and ideas are kept for later and are outside the main progress counts.
